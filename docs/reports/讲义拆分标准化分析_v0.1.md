目标：把现有广义范围讲义拆成基础、普通、培优三个版本，同时保持一节课原有节奏、教师/学生版本一致性，以及后续工作台可审核、可编辑、可追溯。

## 0. 核心结论

这批资料不能按“PDF 页码、题目数量、一级标题”机械拆分。它更适合被建模为：

`同一棵教学树 + 教师/学生双视图 + 学科插件 + 课型插件 + 审核工作流`

其中，“教学树”保证一节课的节奏不被拆坏，“双视图”保证教师版和学生版来自同一源结构，“学科插件”处理公式、图表、语篇、史料、实验等专业对象，“审核工作流”确保 C 端交付前没有答案泄露、图片缺失、题解错配、结构断裂。

v1.0 不建议追求“完全自动生成三套讲义”。更稳的目标是：

1. 先抽取并审核原讲义的结构树。
2. 再对每个教学节点打基础、普通、培优标签。
3. 输出三个版本时只调整题目、支架、难度和教师提示，不改变课堂环节顺序。
4. 所有生成结果必须回挂到原 PDF 页码、原题块、教师/学生配对关系。

## 2. 基线教学树

所有学科可以共享一棵基线树，但不能共享同一套节点解释。

```text
资料包
└─ 学科/学段/年级/季节/系列
   └─ 讲次
      ├─ 课头元信息
      │  ├─ 标题
      │  ├─ 学习目标
      │  ├─ 课程定位
      │  └─ 版本信息
      ├─ 导入与诊断
      │  ├─ 知识导入
      │  ├─ 课程衔接
      │  ├─ 重要性/考试价值
      │  └─ 前置能力检查
      ├─ 知识与方法主干
      │  ├─ 概念/事实/规则
      │  ├─ 方法/模型/模板
      │  ├─ 图表/实验/文本/史料
      │  └─ 易错点/辨析/拓展
      ├─ 例题与任务
      │  ├─ 例题
      │  ├─ 变式
      │  ├─ 题组
      │  └─ 综合任务
      ├─ 训练与迁移
      │  ├─ 基础落实
      │  ├─ 标准训练
      │  ├─ 综合提升
      │  └─ 课后巩固
      ├─ 教师支援层
      │  ├─ 答案
      │  ├─ 解析/详解
      │  ├─ 讲法提示
      │  ├─ 评分标准
      │  └─ 题源/命题意图
      └─ 审核与日志层
         ├─ 原 PDF 页码
         ├─ 图片/表格资产
         ├─ OCR 风险
         ├─ 教师/学生对齐状态
         └─ 人工审核记录
```

这棵树的关键不是节点名字，而是“节奏约束”：每个版本都必须保留同一讲次中的导入、主干、例题、训练、反馈等课堂功能位。分层时可以换题、减支架或加挑战，但不能把培优版变成纯题海，也不能把基础版删到只剩知识点。

## 3. 教师版/学生版处理原则

教师版和学生版不应作为两份独立文档处理，而应作为同一教学树的两个投影。

| 内容类型 | 学生版 | 教师版 | 拆分时处理 |
|---|---|---|---|
| 学习目标 | 保留 | 保留，可能更完整 | 三层版本共享，必要时改写目标难度 |
| 知识导入/课程衔接 | 有时缺失 | 常见 | 可作为教师提示，也可转成学生版简短导入 |
| 知识框架 | 保留，常挖空 | 补全 | 三层都保留结构，挖空量可随层级变化 |
| 例题/训练题 | 保留题干 | 保留题干和答案解析 | 基于题目难度和能力标签替换或筛选 |
| 答案/解析/详解 | 不应出现 | 必须归位 | 严格可见性控制，防止答案泄露 |
| 讲法提示/易错提醒 | 少量可见 | 常嵌入解析或导入 | 教师专属为主，基础版可增加提示 |
| 图表/文本/实验装置 | 必须保留 | 必须保留 | 不得只保留 OCR 文本，需绑定图像资产 |
| 范文/评分标准/开放题示例 | 多为空白任务 | 教师版较完整 | 语文、英语、历史政治需单独建评分/采分字段 |

工作台中建议用 `visibility` 字段控制：`student_all`、`teacher_only`、`student_basic`、`student_standard`、`student_advanced`、`audit_only`。

## 4. 三层拆分的统一口径

基础、普通、培优不是“题目少、中、多”，而是“认知负荷、迁移距离、支架强弱”的差异。

| 层级 | 通用定义 | 题目/任务特征 | 教师支持 |
|---|---|---|---|
| 基础 | 补齐前置，保证能进入本课主干 | 直接识别、单概念、显性条件、标准步骤 | 多提示、多填空、保留方法模板 |
| 普通 | 达成本讲标准课堂目标 | 两步推理、常规变式、典型题型、标准表达 | 常规解析，适量易错提醒 |
| 培优 | 做迁移、综合、隐藏条件、开放表达 | 多条件、多模型、多文本/图表、陌生情境、参数或评价 | 强调策略、反思、命题意图，不提前泄露路径 |

拆分时应先给每个节点打三个标签：

1. `knowledge_level`：概念/规则/方法/综合。
2. `support_level`：强支架/中支架/弱支架。
3. `transfer_level`：原型/近迁移/远迁移。

再由学科插件补充专业难度维度。

## 5. 九科学科结构树

### 5.1 数学

稳定树：课程目标 → 知识导航 → 模块/考点 → 例题 → 变式 → 能力进阶 → 课后练习 → 教师解析。

分层依据：
- 基础：定义、公式、直接代入、单一条件。
- 普通：标准变式、两步计算、常规证明、图形/函数/向量的典型模型。
- 培优：参数讨论、隐含条件、多模型转换、抽象函数、复杂几何辅助线、综合最值。

重点插件：公式识别、图形/几何关系保真、例题-变式绑定、手写批注层识别、答案解析可见性控制。

### 5.2 物理

稳定树：物理量与单位 → 实验/测量 → 规律公式 → 模型过程 → 图像/装置 → 例题训练 → 教师解析。

分层依据：
- 基础：单位、概念、仪器读数、单公式、单对象。
- 普通：两阶段过程、一个隐藏条件、图像解释、常见实验误差。
- 培优：多对象、多过程、临界状态、多方程联立、参数变化、综合模型。

重点插件：单位和上下标规范、图像题绑定、实验装置识别、力图/电路图/光路图保真。

### 5.3 化学

稳定树：课程定位 → 概念定义 → 物质性质/反应规律 → 方程式规范 → 方法模型 → 实验模块 → 例题题组 → 综合应用。

分层依据：
- 基础：化学式、概念、常见现象、常见方程式。
- 普通：离子方程式、电极反应式、热化学方程式、平衡/滴定/守恒标准应用。
- 培优：陌生氧还、过量少量、先后反应、工业流程、实验设计、综合计算。

重点插件：化学式/方程式标准化、元素守恒/电荷守恒校验、实验装置裁剪、流程图资产绑定。

### 5.4 生物

稳定树：课题定位 → 知识骨架 → 模型方法 → 实验/图表链 → 题型训练 → 反馈解析。

分层依据：
- 基础：教材概念、结构功能、显性填空、简单判断。
- 普通：遗传比例、中心法则、膜电位、三率关系、变量控制。
- 培优：特殊遗传比例、科研情境、复杂实验设计、光合呼吸综合曲线、药物阻断机制。

重点插件：生命科学符号规范、遗传图解保真、实验链抽取、曲线/装置/显微图绑定。

### 5.5 英语

稳定树：课程目标 → 语言知识 → 语法/阅读/写作方法 → 例题讲解 → 强化训练 → 语言积累 → 教师答案解析。

分层依据：
- 基础：词汇量低、句法简单、题干显性、模板支架强。
- 普通：中等篇幅、常规语法/阅读策略、独立定位和表达。
- 培优：长难句、多段逻辑、七选五线索交叉、开放写作、风格和语用判断。

重点插件：图像型 PDF OCR、A-G 选项保真、长难句和翻译对齐、写作评分/范文解析、红色答案层识别。

### 5.6 语文

稳定树：课型导入 → 文体/题型知识 → 方法步骤 → 例题带练 → 强化训练 → 范文/译文/答案解析 → 评分或采分点。

分层依据：
- 基础：显性信息提取、固定题型、答题句式、低开放度。
- 普通：独立定位、手法分析、规范表达、多采分点。
- 培优：隐含主旨、文本综合、评价表达、思辨写作、一材多用、答案不唯一。

重点插件：长文跨页合并、文言断句标号保真、题源标准化、范文/素材/评分标准归类、答案解析归位。

### 5.7 历史

稳定树：课时目标 → 时空定位/阶段特征 → 知识梳理 → 深挖辨析 → 史料/图表/地图 → 题目训练 → 教师答案解析。

分层依据：
- 基础：史实、人物、时间、地点、事件顺序。
- 普通：因果、比较、制度演变、阶段特征。
- 培优：史料论证、图表解释、观点评价、多源互证、中外同步。

重点插件：时间轴解析、史料块识别、地图/图表题绑定、开放论述采分点、红色答案区隔离。

### 5.8 地理

稳定树：课程目标 → 知识导入 → 知识导览/思维图 → 考点讲解 → 方法规范 → 图表/地图例题 → 综合训练 → 答案解析。

分层依据：
- 基础：概念识别、单图读取、单因素因果。
- 普通：多因素区位分析、图表判读、规范表达。
- 培优：空间定位 + 图表综合 + 过程机制 + 区域决策评价。

重点插件：地图/剖面图/等值线/光照图保真、区域材料绑定、图文关系审核、规范表达模板。

### 5.9 政治

当前样本主要是高三冲刺包，结构更像“主体术语库 + 答题触发规则 + 材料题训练”，不能直接代表高一高二常规新授讲义。

稳定树：教材模块 → 主体专题 → 核心术语 → 性质/地位/职能/原则 → 依据/意义/对策 → 材料触发 → 答题模板/答案。

分层依据：
- 基础：识别主体、概念、地位、职能。
- 普通：材料映射理论，按“主体 + 行为 + 依据/意义/对策”表达。
- 培优：多主体、多模块、时政情境、材料证据到理论结论的完整论证。

重点插件：主体术语识别、答题触发词、政策/法律/民族宗教表述审核、材料-理论-答案绑定。

## 8. 审核关卡

| 关卡 | 名称 | 审核问题 |
|---|---|---|
| L0 | 文件完整性 | 是否同讲次配对？是否混入课件、题库、补充卷？ |
| L1 | 结构完整性 | 是否保留导入、主干、例题、训练、反馈等课堂节奏？ |
| L2 | 可见性 | 学生版是否残留答案、解析、教师提示？ |
| L3 | 题解绑定 | 每道题是否能找到对应答案/解析？是否跨页错位？ |
| L4 | 资产保真 | 图、表、地图、装置、曲线、长文是否完整绑定？ |
| L5 | 学科规则 | 公式、方程式、单位、术语、断句、选项是否被破坏？ |
| L6 | 分层合理性 | 基础/普通/培优是否只是删题，还是支架和迁移距离不同？ |
| L7 | C 端交付 | 输出版面是否可读、节奏是否像一节课、教师是否可讲？ |

## 9. 高风险清单

1. 页数差异不能作为内容缺失依据。教师版常因答案解析多出 30%-100% 页数。
2. 英语、部分图表密集讲义文本层弱，必须图像化审阅。
3. 数学、物理、化学的公式上下标、箭头、单位、方程式最容易被 OCR 破坏。
4. 生物、地理大量题目信息在图中，只有文字会变成不可教学内容。
5. 语文、英语长文本跨页后，题目、答案、范文容易粘连。
6. 历史、政治的材料出处和主体术语不能被清洗；它们常是采分依据。
7. 政治目前只有高三冲刺包，不足以代表完整政治学科树。
8. 高三资料有大量复习、笔记、补充卷，必须和标准讲义主树区分。
9. “深挖点、易错点、温馨提醒”不一定是教师专属，需看学生版是否保留。
10. 文件名版本标记不稳定，必须结合内容识别教师/学生版。

## 10. v1.0 建议路线

第一阶段：建立主树和审核样本  
每个插件族选 1-2 份代表讲义，人工确认结构树、可见性规则、题解绑定规则。

第二阶段：建立字段和标注规范  
先支持 `doc -> node -> task -> answer/explanation -> asset` 的闭环，不急于自动改写讲义。

第三阶段：做基础/普通/培优拆分试点  
每科先选一讲，保留同一课堂节奏，只改题目梯度、支架强弱和教师提示。

第四阶段：进入工作台式 agent  
工作台重点不是“一键生成”，而是“模型预拆 + 人工审核 + 可追溯编辑 + C 端版面预览”。

建议第一批试点：

| 插件族 | 推荐学科/讲义类型 | 理由 |
|---|---|---|
| 公式模型实验计算类 | 数学基本不等式、化学氧化还原、物理力学模型 | 题目梯度清楚，容易验证分层效果 |
| 图表机制过程类 | 生物遗传规律、地理等值线/经纬网 | 图表资产要求高，能验证保真能力 |
| 文本语篇表达类 | 语文小说阅读、英语七选五/写作 | 长文本和答案边界复杂，能验证审核台价值 |
| 材料论证主体术语类 | 历史材料题、政治主体专题 | 采分点和材料映射明显，适合做论证型插件 |

## 11. 可见的“必备点一级”

拆分讲义过程中，一级必备点建议固定为 8 个：

1. 课程目标：本课要解决什么能力问题。
2. 前置与导入：学生为什么现在学、缺口在哪里。
3. 知识主干：核心概念、规则、事实、模型。
4. 方法路径：解题步骤、阅读策略、实验方法、答题模板。
5. 例题示范：教师带学生完成的标准样例。
6. 学生训练：学生独立或半独立完成的任务。
7. 反馈解析：答案、解析、采分点、易错提醒。
8. 总结迁移：本课沉淀和课后巩固。

任何基础/普通/培优版本都要能映射回这 8 个一级点。允许某一讲没有显性标题，但不允许缺少课堂功能。
