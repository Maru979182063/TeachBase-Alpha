# 倍长中线与截长补短（教师版）学段差异审计 v0.1

## 1. 本次要回答的问题

对样本：

- `C:/Users/EDY/Documents/WXWork/1688857912801359/WeDrive/领世培优/领世一对一数学学科资料/初中数学/01标准化讲义/01暑假/02初二/第2讲 倍长中线与截长补短（教师版）.pdf`

做一次真实试跑，判断：

- 初中数学和高中数学之间是否已经出现明显的学段差异
- 这个差异是否大到需要独立 skill
- 还是应该继续保持一个总 skill，但在 runtime 内拆成更细的 profile

## 2. 样本特征

- 页数：50 页
- 学段：初中二年级
- 学科：数学，偏几何证明与辅助线

版式观察：

- 第 1 页是大幅封面 + `课程目标 / 知识导航`
- 第 2 页是长段落 `知识导入`
- 第 4 页开始进入 `例题讲解`
- 页内高频出现：
  - `考点1`
  - `【例1】`
  - `【变式2-1】`
  - `课后练习1`
  - `要点回顾`

也就是说，这份讲义的题锚体系不是单一的：

- 蓝色组件挂件
- 黑色/灰色文本锚点
- `【例】/【变式】/课后练习` 混合存在

## 3. 试跑结果

使用脚本：

- `tools/teacher_pdf_visual_question_split_v02.py`

输出目录：

- `outputs/ingress_splitter_v0.1/codex_trial_junior_geometry_visual_v02_20260623/`

结果：

- `anchors = 11`
- `segments = 53`
- `questions = 5`

这是一个非常强的异常信号：

- 页数 50
- 段数 53
- 真正题块只有 5

说明现有主线并不是“略有误差”，而是 **对这类初中几何讲义整体不成立**。

## 4. 最关键的发现

### 发现 A：组件识别部分成立，但题块切分几乎失效

从组件总览看，系统能把很多页面切成独立段：

- `考点...`
- `强化训练`
- `课后落实`

但进入单题层之后几乎没有继续下钻。

直接表现为：

- `53` 个 segment
- 只有 `5` 个 question

这不是题少，而是：

- 组件级能跑
- 单题级断掉

### 发现 B：首页 `知识导航` 的表头 `考点` 被误识别成 checkpoint

证据代码：

- `tools/teacher_pdf_visual_question_split_v02.py:291-300`

当前规则是：

- 只要文字行 `startswith("考点")`
- 就直接当成 `checkpoint` anchor

但这份初中样本第一页 `知识导航` 表格里就有表头 `考点`。

结果是：

- 首页及前几页被错误挂到 `checkpoint` 体系下
- 并进一步污染了后续段切分

### 发现 C：真正的初中题锚没有被当成题锚

这份样本里真正高频的题锚是：

- `【例1】`
- `【变式2-1】`
- `课后练习1`

但当前题号规则是：

- `tools/teacher_pdf_visual_question_split_v02.py:26`
- `QUESTION_START = re.compile(r"^\s*(\d{1,2})\s*[．.、]\s*")`

也就是说当前只把：

- `1.`
- `2．`
- `3、`

这类行首数字当成题起点。

这对高中数学还勉强够用，
但对这份初中几何明显不够。

### 发现 D：`知识梳理` 被误切成 `Q0`

证据：

- `tq_001_考点_强化训练_Q0.png`

实际内容是：

- `知识梳理`
- `倍长中线`
- `倍长类中线`

这是知识页，不是题目。

系统虽然把它标成了：

- `NEEDS_MANUAL_REVIEW`

但这仍说明：

- 初中几何中的 `知识梳理/要点回顾` 与题页在版式上更接近
- 需要专门的“非题型页排除规则”

### 发现 E：`要点回顾` 再次被误切成 `Q0`

证据：

- `tq_004_考点_截长补短构造全等_强化训练_Q0.png`

这个 crop 实际是一整页思维导图，不是题目。

这和前面高中数学样本里 `要点回顾` 被切成 `Q0` 的问题一致，
但在初中几何里更严重，因为这类页更常见。

### 发现 F：`课后落实` 被整串吞并，没有逐题切开

证据：

- `tq_005_考点_截长补短构造全等_课后落实_Q0.png`

该题块直接覆盖：

- 第 45 页
- 第 46 页
- 第 47 页
- 第 48 页
- 第 49 页

也就是说，系统把整组 `课后练习` 看成了一个无题号整块。

这是非常明确的学段差异信号：

- 在初中几何里，课后题组经常靠 `课后练习1 / 课后练习2 / ...`
- 或 `【变式】` 内部切分
- 并不总是用标准 `1. 2. 3.` 起题

### 发现 G：仅有的两个“正常题块”也不完全可靠

`tq_002` 和 `tq_003` 是本次仅有的两个 `VISUAL_REVIEWED_V02`。

但其中 `tq_002` 实际内容是：

- `定义：截长补短分截长法与补短法两种...`

更像知识点条目或方法说明，
未必应该直接落成题目。

这意味着：

- 即使被识别成了 `Q1/Q2`
- 也可能是知识条目误入题流

## 5. 和前两个样本的对比

### 英语教师版

- 页数：43
- 通用主线结果：`0 anchor / 0 segment / 0 question`

结论：

- 英语阅读教师版几乎完全不适配当前通用主线

### 高中数学教师版

- 页数：33
- 通用主线结果：`19 anchor / 49 segment / 47 question`

结论：

- 高中数学在组件层和题块层都基本能跑
- 但仍有跨页边界和 `Q0` 误切问题

### 初中数学教师版

- 页数：50
- 通用主线结果：`11 anchor / 53 segment / 5 question`

结论：

- 组件层部分可用
- 题块层基本不成立

### 汇总判断

三份样本放在一起，结论已经非常清楚：

- `英语阅读`
- `高中数学`
- `初中几何`

不是同一层级的 profile 差异。

其中：

- 高中数学和初中数学都叫“数学”
- 但在题锚体系上已经出现了明显学段分化

## 6. 这是否意味着要单独做 skill

### 结论

**仍然不建议拆成多个独立 skill。**

但建议把数学内部 profile 至少拆成两层：

1. `senior_math_standard_teacher`
2. `junior_geometry_text_anchor_teacher`

原因是：

- 总 workflow 仍然一致
- 仍然是视觉优先
- 仍然是组件先于题块
- 仍然输出同一套 JSON/XLSX/contact sheet 契约

不同的是：

- 初中几何的题锚不再主要是 `1. 2. 3.`
- 而是 `【例】/【变式】/课后练习N`
- 加上图形、要点回顾、知识梳理更频繁穿插

所以应该拆的是：

- runtime profile

而不是：

- skill 工作流

## 7. 初中学段 profile 应补的规则

### 规则 1：首页和导入页禁触发 checkpoint

像这份样本的第一页：

- `知识导航` 表格中的表头 `考点`

不应触发正式 `checkpoint` anchor。

建议：

- 首页上的 `考点` 表头降权
- 表格头部 `考点` 不进入结构树

### 规则 2：把 `【例N】`、`【变式N-M】` 作为一级题组锚

这是这份样本最核心的缺口。

建议 runtime 在初中几何 profile 中显式识别：

- `【例1】`
- `【例2】`
- `【变式2-1】`
- `【变式5-1】`
- `课后练习1`

这些不只是文字说明，而是题组起点。

### 规则 3：`课后练习N` 要能连续拆题

目前 `课后落实` 直接被吞成五页一个块。

应改为：

- 先识别 `课后练习1/2/3...`
- 再在每个练习块内识别子题或保持单练习为一块

### 规则 4：`要点回顾 / 知识梳理 / 知识导入` 默认不出题

这些内容可以保留为组件输出，
但默认不应该进入题块。

若要保留，也应是：

- component only
- 非 question

### 规则 5：多问一题保持整题，不按 `(1)(2)(3)` 拆散

初中几何里大量存在：

- 同一道 `【变式】` 下挂 `(1)(2)(3)`
- 同一个图服务多个小问

因此应优先把：

- `【例】/【变式】`

作为外层题块，
而不是急着按小问编号拆碎。

## 8. 哪些放 runtime，哪些放审核 UI

### 应进 runtime 的

- `【例】/【变式】/课后练习` 文本锚识别
- 首页 `考点` 表头排除
- `知识梳理 / 要点回顾` 不出题
- 课后题组分页连续切分
- 多问同图的整块保留

### 应放审核 UI 的

- 某个 `【变式】` 内部是否再细拆
- 个别图文重叠题的边界修正
- 低置信度 `Q0` 的去留判断

## 9. 最终判断

这次试跑说明：

- 初中数学和高中数学之间，已经存在 **明确的学段级差异**
- 差异核心不在“内容更简单或更难”
- 而在“题锚体系、知识页比例、图文组织方式都不同”

所以后续最合理的结构不是：

- 一个数学 profile 统吃

而是：

- 高中数学 profile
- 初中几何 profile

在这两者之上，再共用同一个视觉拆解总 skill 和统一审核台。
