# 可靠金标标准 v2026-06-25

本标准以最近逐图复核的高风险题 `case_011 / case_025 / case_113 / case_114 / case_135 / case_136` 为基准，用于整理剩余 194 题，并逐步形成一批可直接作为正式评估基准的可靠金标。

## 核心原则

1. 题图是唯一真值源。
2. 不参考 PDF 文本层去“纠正”题图，除非题图本身就是错的，而本轮目标不是修题，而是忠实转录。
3. 不做描述性改写，不做教学口吻润色，不做“看起来更合理”的数学修正。
4. 图片中不可见的内容不补写；裁切不完整就按可见内容落标，并显式标注原因。

## 字段要求

逐题至少核查以下字段：

- `gold_stem_text_md`
- `gold_answer_text_md`
- `gold_analysis_text_md`
- `manual_status`
- `source_issue`
- `manual_review_note`

## 严格审核口径

### 1. 按图逐字段

- 题干、答案、解析分开核，不允许把解析内容搬进题干，也不允许把题干重组成另一种表达。
- 只要原图中有标题、例题号、课后练习号、年份、括号、序号，就要保留。
- 原图是残缺裁切时，只录可见部分，不脑补前文后文。

### 2. 数学符号优先

- 公式、加减号、分式、根号、上下标、角标、集合符号、逻辑符号必须优先对图。
- `+ / - / = / ≠ / ∈ / ∉ / ⊥ / ∥ / ∠ / △ / ▱` 等符号不允许用“相近文本”替代。
- 图形记号如果原图可见，就按原图录，不替换成另一个常见记号。

### 3. 排版层级保留

- 分问结构、证明结构、方程组结构、分类讨论结构要尽量贴近原图。
- 长题中的方程组必须保留成多行系统，不能串成一行。
- 允许必要的 Markdown + LaTeX 规范化，但不能改变原有数学关系。

### 4. 不替源纠错

- 如果题图中公式、答案、解析彼此不一致，金标仍按题图可见内容录入。
- 这类情况在 `manual_review_note` 里说明“源图存在不一致”，但不擅自改成数学正确版本。

## 状态分层

### `strict_audited`

满足以下条件：

- 已逐图逐字段人工核过
- 无描述性改写
- 关键符号、标题、层级已核实
- 可以直接用于正式评估

### `candidate_only`

满足以下条件：

- 当前与自动结果差异较少
- 但尚未完成逐图严格复核
- 暂不计入最终可靠金标子集

### `needs_strict_review`

满足以下任一条件：

- `manual_status` 为 `corrected` 或 `source_incomplete`
- 评估中 `all_basic_exact = false`
- 高风险长解析、证明题、方程组题、折叠题、反比例综合题、复数/符号密集题

## 当前使用方式

1. 先从 `needs_strict_review` 中按风险优先级清理。
2. 每完成一题严格复核，就将其加入可靠金标子集。
3. `candidate_only` 不直接当正式评估基准，需后续补审后才能转正。
