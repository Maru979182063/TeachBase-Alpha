## 审查对象

本次审查对象不是现有 runtime 的自动转录结果，而是我对 10 道题进行的人工视觉抄录结果，流程为：

1. 对整题图做 `Pass 1` 原始 Markdown 抄录
2. 对可疑 span 做局部复核
3. 输出 `Pass 2` 的 Markdown + LaTeX 规范稿

题目覆盖：

- 高中数学 5 题
- 初中几何 5 题

## 人工核查范围

本次已完成以下人工核查：

- 10/10 题整题图重新目视复核
- 重点公式题与证明题再次核对
- 对报告中的题干、选项、答案、解析链条做一致性检查

本次核查的重点不是“解题是否最优”，而是：

- 是否忠实抄录原题
- 是否保留原题结构
- 是否把公式规范转成 LaTeX
- 是否把图片强依赖题保留为图片证据驱动

## 审查结论

### 1. 这 10 题的人工结果可作为小规模测试集样本

结论：`可以`

原因：

- 题干、选项、答案、解析主体均已人工对照题图检查
- 公式题已转成可落库的 Markdown + LaTeX 形式
- 几何题中的图形依赖关系没有被错误抹平成纯文本

### 2. 这 10 题不能证明当前 runtime 已可自动交付

结论：`不能`

原因：

- 这批结果依赖人工视觉抄录与二次 span 审查
- 现有 runtime 的自动转录结果此前已审过，整体仍不可用
- 当前能稳定的是“视觉切块与题图归属”，不是“自动公式转录”

### 3. 二次 span 精修是有效动作，但前提是首轮文本不能太坏

结论：`成立`

原因：

- 对 `tq_002`、`tq_003`、`tq_018`、`tq_025` 这类公式题，二次 span 精修主要解决的是：
  - 分式规范化
  - 根式规范化
  - 三角恒等式版式规范化
- 对 `tq_021` 这类几何证明题，二次精修主要解决的是：
  - 角关系表达
  - 共线与全等推理层级
- 但如果首轮文本已经出现大量错字、漏式、错符号，二次精修并不能自动救活

## 按交付字段看现状

以你现在定义的字段为准：

- `题干`：人工流程可产出；当前自动流程不稳定
- `题干图片`：可稳定保留
- `答案`：人工流程可产出；自动流程在简单题可碰运气，不可作为标准能力
- `解析`：人工流程可产出；自动流程在公式题、证明题不稳定
- `解析图片`：可稳定保留

## 现阶段最真实的状态

一句话：

`视觉拆解已经接近可用，题目录入层还没有完成产品化。`

更具体地说：

- 你们现在已经有了比较像样的视觉主骨架
- 但“文本可落库”这一层，尤其是数学公式和证明链，仍然需要单独建设
- 所以这次 10 题测试集更适合作为：
  - 评测基准样本
  - 后续公式转录 prompt / skill / 局部精修流程的对照组

## 建议怎么对外表述

如果你要给领导一个稳妥说法，我建议这样表述：

1. 已完成视觉优先路线的小样验证，题块与图片归属方向正确。
2. 已完成 10 题人工金标测试集，可作为后续自动转录评测基线。
3. 当前短板不在切块，而在数学题文本化，尤其是公式与证明解析转写。
4. 下一步不是继续堆 OCR，而是把“首轮抄录 + 可疑 span 定位 + 局部高清精修”做成可执行 runtime。

## 当前建议

如果只做最近三天的调试测试，我建议把目标收敛成两件事：

1. 先提交一份小而硬的测试集
   - 就是这 10 题人工金标
   - 每题保留题图、可疑 span、Pass 1、Pass 2

2. 再提交一份自动结果对照
   - 用同一批题跑现有 runtime
   - 按字段打失败标签
   - 让问题具体落到“错在题干、公式、答案、解析、图文归属中的哪一层”

这样汇报会很稳：

- 既证明方向没错
- 也不会把现状吹成“自动录题已经好了”
