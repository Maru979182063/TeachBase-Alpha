# 讲义拆分构建 v0.1

这个目录用于验证第一条主线：把现有标准讲义拆成可审核、可分层、可预组装的结构化节点。

当前目标不是“一键生成最终讲义”，而是跑通：

```text
教师/学生版配对
→ 文本与页面抽取
→ 基底课堂结构识别
→ 题目/答案/解析绑定
→ 学科插件打标
→ 输出可审核 JSON 和人工复核摘要
```

## 目录

```text
split_builder/
├─ schemas/
│  └─ lesson_split.schema.json
├─ config/
│  ├─ base_tree.json
│  └─ plugins/
│     └─ math.json
└─ prototype_splitter.py
```

## 第一版策略

1. 以学生版题干作为学生可见主干。
2. 以教师版同题块补全答案、解析、分析、详解。
3. 以 `讲次 -> 课堂环节 -> 考点 -> 题块` 作为数学首个拆分结构。
4. 先用规则保证边界稳定，再把难度、能力、风险交给插件可调。

## 后续扩展

后续每个学科只新增或调整插件，不改变主结构：

- 数学：公式、例题-变式、考点题组。
- 化学：方程式、实验、流程图、守恒校验。
- 语文：长文、题源、答案采分点、范文。
- 英语：语篇、选项、翻译、写作评分。
- 生物/地理：图表、实验链、地图资产。
- 历史/政治：材料、术语、采分点、论证结构。
