# 讲义拆分构建

这个目录保留了项目较早期的一条实验主线：把标准化讲义拆成可审校、可分层、可重组的结构化节点。

当前目标不是一键生成最终讲义，而是验证一套稳定的拆分骨架：

```text
教师版 / 学生版配对
-> 文本与页面抽取
-> 课堂结构识别
-> 题目 / 答案 / 解析绑定
-> 学科插件补充语义
-> 输出可审查 JSON 与人工复核材料
```

## 当前定位

- 这是独立的实验子工作流，不是当前主线运行时的唯一入口
- 适合查看结构拆分思路、schema 设计和学科插件化方向
- 不直接代表当前 `runtime/postgres` 那条后端验证基线

## 目录说明

```text
split_builder/

|     |- math.json

```

## 设计原则

1. 先把结构边界稳定下来，再逐步提升语义质量。
2. 先保证题块、答案、解析的绑定关系，再补充能力点和难度标签。
3. 各学科优先通过插件扩展，而不是改动主拆分框架。

## 后续扩展方向

- 数学：公式、图形、例题链路、考点题组
- 化学：方程式、实验流程、守恒校验
- 语文：长文阅读、题源、采分点、范文结构
- 英语：语篇、选项、翻译、写作评分
- 生物 / 地理：图表、实验链、地图资源
- 历史 / 政治：材料、术语、采分点、论证结构
